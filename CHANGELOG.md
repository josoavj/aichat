# Changelog

Toutes les modifications notables apportées au projet FocusFlow seront répertoriées dans ce fichier.

## [1.0.0] - 2024-09-10

### Ajouté
- Interface de chat IA moderne utilisant Gemini 1.5 Flash.
- Système de gestion de tâches local avec SQLite.
- Section Journal / Brain Dump pour la capture d'idées.
- Mode Focus (Pomodoro) avec minuteur circulaire.
- Écran de statistiques avec graphiques de productivité.
- Système de notifications locales pour les rappels proactifs.
- Gestion du thème (clair/sombre) et personnalisation de la police.

### Modifié
- Refonte complète de l'architecture pour le mode "Local-First".
- Optimisation du Persona de l'IA pour les utilisateurs hyperactifs.
- Migration vers Material 3.

### Supprimé
- Dépendances et configurations Firebase.
- Utilisation des émojis dans l'interface et les logs.
