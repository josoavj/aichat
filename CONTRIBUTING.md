# Contribution à FocusFlow Assistant

Merci de l'intérêt que vous portez à l'amélioration de FocusFlow ! Les contributions sont essentielles pour rendre cet outil plus efficace pour la communauté TDAH/Hyperactive.

## Comment contribuer ?

### 1. Signaler des bugs

Si vous trouvez un bug, veuillez ouvrir une "Issue" en décrivant :
- Le comportement attendu.
- Le comportement observé.
- Les étapes pour reproduire le problème.

### 2. Proposer des fonctionnalités

Toute idée permettant de réduire la charge mentale ou d'améliorer le focus est la bienvenue.

### 3. Soumettre des changements (Pull Requests)

1. Forkez le dépôt.
2. Créez une branche pour votre modification (`git checkout -b feature/nom-de-la-feature`).
3. Assurez-vous que votre code passe l'analyse statique (`flutter analyze`).
4. Committez vos changements avec des messages clairs.
5. Poussez votre branche et ouvrez une Pull Request.

## Règles de style

- **Pas d'émojis** dans le code source ou les messages d'interface utilisateur.
- Utilisez **Material 3** pour les nouveaux composants.
- Respectez l'architecture **Local-First** (pas de dépendances cloud obligatoires).
- Documentez les nouvelles fonctions de l'IA dans le Persona si nécessaire.
